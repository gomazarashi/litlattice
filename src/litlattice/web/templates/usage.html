使い方

LitLatticeは、論文とその引用関係を管理・探索するためのツールです。 CLI（llat）とこのWeb画面から、同じデータベースの論文を追加・管理し、引用関係を探索できます。

基本的な考え方

論文
一つの論文を表す記録です。タイトルやDOI・arXiv IDなどの識別子を持てます。タイトルが同じでも、自動的に同じ論文とはみなしません。
ライブラリ
自分が管理対象として選んだ論文の集まりです。論文はライブラリに登録しなくてもデータベースに保存できます。ライブラリから外しても論文自体は削除されません。
引用 A → B
「論文Aが論文Bを引用している」ことを表します。向きは常にこの意味です。引用を登録してもライブラリの状態は変わりません。
参考文献
ある論文が引用している論文です（この論文 → 相手）。
被引用
ある論文を引用している論文です（相手 → この論文）。

画面の見方

画面内容
概要論文数・ライブラリ件数・引用数と、被引用数の多い論文を表示します。
論文データベース内のすべての論文の一覧です。タイトルをクリックすると詳細を開きます。
論文の詳細識別子、ライブラリ状態、参考文献、被引用を表示します。ここからライブラリへの追加・解除、メタデータの取得、引用の探索ができます。
論文を追加DOI・arXiv ID・OpenAlex IDから取り込むか、タイトルで検索して候補を確認できます。
PDFこのマシンのPDFと関連付いた論文を表示します。未解決のPDFを絞り込み、詳細から同定の手がかりを確認できます。
引用グラフライブラリに登録した論文と、それらの間の引用を表示します。ノードの大きさはPageRank（このグラフ内での重要度）です。拡大・縮小、ドラッグでの移動、「全体を表示」、論文を探す操作ができます。ノードをクリックすると詳細を開きます。

記号

  • ● ライブラリ登録済み / ○ ライブラリ未登録
  • → 参考文献（この論文が引用している）、← 被引用（この論文を引用している）
  • 引用グラフでは、ライブラリ登録済みの論文を塗りつぶし、未登録の論文を点線の白抜きで示します。論文の詳細にある「周辺グラフを見る」では、起点の論文の左に被引用、右に参考文献を表示できます。

Webでの操作

  1. 「論文を追加」で識別子を入力して取り込むか、タイトルを検索して候補を確認します。検索しただけでは保存されません。
  2. 管理対象にする論文は、詳細画面でライブラリに追加します。取り込みやPDFの関連付けでは自動追加されません。
  3. 論文の詳細で「メタデータを取得」を押すと、OpenAlexから不足するタイトル・出版年・識別子を補います。
  4. 引用を探索するには、深さ（1・2）、方向、上限（20・50・100件）を選びます。保存した引用は周辺グラフで確認できます。
  5. 「PDF」で未解決のものを選び、手がかりと候補を確認して関連付けます。候補がなければ識別子から論文を取り込むか、タイトル検索で論文を追加して、その論文のUUIDを入力します。

PDFの関連付けを解除しても、論文・PDFの記録・実ファイルは残ります。PDFフォルダの登録とscanはCLIから行います。

OpenAlexと通信する操作は時間がかかることがあります。「通信中…」の間は完了を待ってください。失敗したときは画面に理由を表示します。

CLIでの操作

この画面が参照しているデータベースを操作するには、--db に同じパスを指定します。 以下の例ではそのパスを $DB としています。 

DB={{ db_path }}
コマンド内容
llat --db "$DB" initデータベースを作成・更新します。最初に一度実行します。
llat --db "$DB" paper create --title "…" --doi …論文を作成します。--doi / --arxiv は複数指定できます。ライブラリには追加されません。
llat --db "$DB" paper import --doi …
llat --db "$DB" search "タイトル"		OpenAlexから論文を取り込む、または検索候補を表示します。検索だけでは保存しません。
llat --db "$DB" paper fetch ID
llat --db "$DB" expand ID --depth 1 --max-nodes 20		メタデータを補い、引用を探索して保存します。ライブラリには自動追加しません。
llat --db "$DB" src add /path/to/pdfs
llat --db "$DB" scan		PDFフォルダを登録し、ファイルを認識します。PDFのダウンロードやライブラリへの追加はしません。
llat --db "$DB" doc list --unlinked
llat --db "$DB" doc show DOCUMENT_ID		未解決のPDFと、同定の手がかりを表示します。
llat --db "$DB" doc link DOCUMENT_ID PAPER_ID
llat --db "$DB" doc unlink DOCUMENT_ID PAPER_ID
llat --db "$DB" doc import DOCUMENT_ID --doi …		PDFと論文の関連付け・解除、論文の取り込みと関連付けを行います。
llat --db "$DB" paper list論文の一覧を表示します（L はライブラリ登録済み）。
llat --db "$DB" show ID論文の詳細を表示します。
llat --db "$DB" lib add ID
llat --db "$DB" lib remove ID		論文をライブラリに追加するか、ライブラリから外します。
llat --db "$DB" citation add 引用元ID 引用先ID「引用元が引用先を引用している」ことを登録します。
llat --db "$DB" citation list ID --direction both参考文献（->）と被引用（<-）を表示します。references / citations で片方だけにできます。
llat --db "$DB" path 始点ID 終点ID引用の向きに沿った最短経路を表示します。逆向きには辿りません。
llat --db "$DB" serveこのWeb画面を起動します（http://127.0.0.1:8000/、--port で変更可）。

開発環境では各コマンドの先頭に uv run を付けます。論文のIDは paper list や各画面に表示されるUUIDです。

基本的な流れ

  1. init でデータベースを用意する
  2. PDFフォルダを src add で登録して scan するか、「論文を追加」で論文を取り込む
  3. 未解決のPDFは「PDF」の詳細で手がかりを確認して関連付ける
  4. 管理したい論文だけを lib add でライブラリに追加する
  5. 論文の詳細から引用を探索するか、expand を実行する。手動登録には citation add を使う
  6. citation list や path、このWeb画面で引用関係を探索する

CLIで変更した内容は、ブラウザを再読み込みすると反映されます。

注意

  • 検索結果や曖昧なPDFの候補は、自動で一つの論文へ統合しません。識別子と候補を確認して選んでください。
  • サーバーの再起動後や、ページを開いてから長時間経過した場合は、再読み込みしてからフォームを送信してください。
  • このサーバーはローカル利用・デモ用です。127.0.0.1 でのみ待ち受け、認証はありません。外部ネットワークには公開しないでください。
